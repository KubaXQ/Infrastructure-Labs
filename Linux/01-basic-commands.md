# Linux - Basic Commands
pwd - shows the current working directory

whoami - tells us which user account we are working with

ls - shows files and directories inside the current directory

ls something - shows files and directories inside the specified directory

man - shows detailed documentation about a command and how to use it

--help - shows basic information about a command and its available options
## Navigation
cd - allows us to move from one directory to another

cd .. - moves us one directory up

cd ~ - takes us to our home directory

cd / - takes us to the root directory

cd - - takes us back to the previous directory
## Files and Directories
mkdir - creates a new directory

touch - creates a new empty file

cat - displays the content of a file

cp - copies files or directories from one location to another

mv - moves files or directories to another location or renames them

rm - removes files or directories
## System Information
hostname - shows the name of our computer

hostnamectl - shows information about the system and hostname

uname -a - shows information about the Linux kernel and system

uptime - shows how long the system has been running

df -h - shows disk space usage

du -sh - shows how much disk space a file or directory uses

top - shows running processes and how much CPU and RAM they are using

lscpu - shows information about the CPU

free -h - shows information about RAM and swap memory usage
